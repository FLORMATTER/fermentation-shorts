8. Estrutura da página

Todo arquivo HTML tem a mesma estrutura de base:

<!DOCTYPE html>     ← avisa que é HTML
<html>              ← começa a página
  <head>            ← informações (não aparece na tela)
  </head>
  <body>            ← o que aparece na tela
  </body>
</html>             ← termina a página

9. Teste você mesmo

  1. Abra este arquivo no Bloco de Notas (botão direito → Abrir com)

  3. Troque o texto para <h1>Olá, eu consegui!</h1>
