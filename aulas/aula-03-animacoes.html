Aula 3 — Como fazer uma animação

Aula 3 de 4. Aqui você aprende o @keyframes, que é o motor de toda animação.

Como usar esta aula: leia de cima para baixo. Cada exemplo tem o código e logo abaixo o desenho funcionando. Vá comparando os dois.

1. A ideia por trás de tudo

Uma animação no navegador é a mesma coisa que um flipbook (aquele livrinho que você folheia rápido e o desenho parece se mexer).

O navegador faz isso 60 vezes por segundo:

  1. Apaga o desenho
  2. Desenha de novo, um pouquinho diferente
  3. Repete

É a diferença entre os desenhos que cria o movimento. Você não precisa desenhar tudo — só precisa dizer onde começa e onde termina.

2. O @keyframes — a peça principal

O @keyframes é onde você descreve o movimento. Ele tem sempre esta cara:

@keyframes girar {
  0%   { transform: rotate(0deg) }
  100% { transform: rotate(360deg) }
}

Lendo em voz alta:

  • @keyframes girar — estou criando uma animação com o nome girar
  • 0% — como está no começo
  • 100% — como está no fim
  • rotate(0deg) → rotate(360deg) — de 0 graus até 360 graus (uma volta completa)
Regra: o nome que você inventa em @keyframes é o mesmo nome que você vai usar depois. É como dar nome a um filho.

3. Primeiro exemplo — girar

Aqui está o código completo:

@keyframes girar {
  0%   { transform: rotate(0deg) }
  100% { transform: rotate(360deg) }
}

.bolinha {
  animation: girar 2s linear infinite;
}

Agora veja funcionando:

Repare: eu não mexi em cada bolinha. Só girei o grupo inteiro. Uma animação, quatro bolinhas girando.

4. Lendo a linha mágica

A linha mais importante é esta:

animation: girar 2s linear infinite;

Ela tem 4 pedaços. Nesta ordem:

Pedido O que significa
girar Qual animação usar (o nome do @keyframes)
2s Quanto tempo dura uma volta (2 segundos)
linear Velocidade sempre igual (não acelera nem freia)
infinite Nunca para. Repete pra sempre

Decore esta linha. 90% das animações usam ela com pequenas trocas.

5. Segundo exemplo — pular

Aqui uso 0%, 100% juntos no mesmo bloco:

@keyframes pular {
  0%,100% { transform: translateY(0) }
  50%     { transform: translateY(-30px) }
}

Por que? Porque o começo e o fim são iguais (embaixo), e o meio é diferente (em cima). Assim o pulo vai e volta sozinho, sem "pulo" na emenda.

Detalhe importante: aqui troquei linear por ease-in-out. Isso faz o movimento acelerar e freiar — muito mais natural que velocidade constante.

6. Terceiro exemplo — respirar (escala)

Em vez de mover, a gente aumenta e diminui:

@keyframes respirar {
  0%,100% { transform: scale(1) }
  50%     { transform: scale(1.5) }
}

scale(1) é o tamanho normal. scale(1.5) é uma vez e meia maior.

⚠ Atenção: sem transform-origin: center, o círculo cresce "puxando" para o canto. Isso acontece porque o SVG cresce a partir do ponto (0,0), não do meio. Sempre coloque essa linha quando usar escala.

7. Quarto exemplo — mudar de cor

Até agora mexi na posição. Também dá pra mexer na cor:

@keyframes mudarCor {
  0%   { fill: #7d8c46 }
  50%  { fill: #d85a30 }
  100% { fill: #7d8c46 }
}

No SVG, a cor de preenchimento se chama fill (não é color!).

8. Quinto exemplo — subir e desaparecer

Este é o efeito das bolhas que aparecem em vários dos seus arquivos:

@keyframes subir {
  0%   { transform: translateY(0); opacity: 0 }
  30%  { opacity: .9 }
  100% { transform: translateY(-90px); opacity: 0 }
}

Lendo em voz alta:

  1. Começa no lugar, invisível (opacity: 0)
  2. Chegando em 30%, fica bem visível (opacity: .9)
  3. No fim, subiu 90 pixels e sumiu de novo

O resultado é a bolha aparecendo, subindo e desaparecendo — em loop.

Repare nos .5s e 1s no final. Isso é o atraso (delay) — serve pra elas não subirem todas juntas. Fica muito mais natural.

9. Sexto exemplo — as duas mãos massageando

Este é de verdade, tirado dos seus arquivos. Duas mãos, mesma animação mas espelhada:

@keyframes massagearE {
  0%,100% { transform: translate(0,0) scale(1,1) }
  50%     { transform: translate(14px,-7px) scale(.93,1.05) }
}

@keyframes massagearD {
  0%,100% { transform: translate(0,0) scale(1,1) }
  50%     { transform: translate(-14px,-7px) scale(.93,1.05) }
}

Olhe a diferença: a primeira move +14px (direita), a segunda -14px (esquerda). E a escala .93,1.05 faz a mão ficar um pouco mais baixa e mais larga — como se estivesse apertando de verdade.

O .45s na mão direita faz ela ficar fora do compasso — uma aperta enquanto a outra solta. É isso que dá a sensação de massagem real.

10. Como colocar no seu HTML

São 2 passos, sempre:

Passo 1 — Escreva o @keyframes dentro do <style>

<style>
  @keyframes girar {
    0%   { transform: rotate(0deg) }
    100% { transform: rotate(360deg) }
  }
</style>

Passo 2 — Chame a animação no elemento

<circle cx="50" cy="50" r="20" fill="#7d8c46"
        style="animation: girar 2s linear infinite;" />

Pronto. É só isso.

11. Resumo dos movimentos

Quero que... Use Exemplo
gire rotate() rotate(360deg)
ande para o lado translate() translate(20px, 0)
suba ou desça translateY() translateY(-30px)
cresça ou encolha scale() scale(1.5)
fique transparente opacity opacity: 0
mude de cor (SVG) fill fill: #d85a30
Dica: você pode juntar vários no mesmo bloco, separados por espaço:

transform: translate(14px,-7px) scale(.93,1.05)

Isso move e muda o tamanho ao mesmo tempo.

12. As 4 velocidades

Palavra Como se move
linear Velocidade igual do começo ao fim
ease-in-out Acelera no meio, freia nas pontas (mais natural)
ease-out Começa rápido, vai freando
ease-in Começa devagar, vai acelerando

13. 🎯 Teste você mesmo

Esta é a parte que faz você aprender de verdade. Faça agora:

  1. Abra este arquivo no Bloco de Notas
  2. Ache esta linha (perto do começo do <style>): 
    @keyframes girar {
  0%   { transform: rotate(0deg) }
  100% { transform: rotate(360deg) }
}
  3. Troque os segundos da chamada. Ache: 
    animation: girar 2s linear infinite;
    e mude para: 
    animation: girar 0.4s linear infinite;
  4. Salve (Ctrl + S) e aperte F5 no navegador

Agora o círculo gira 5 vezes mais rápido. Você acabou de controlar uma animação.

Experimentos para tentar:
  • Troque rotate(360deg) por rotate(90deg) — vira um balanço
  • Troque girar por respirar no nome
  • Troque infinite por 3 — para depois de 3 voltas
  • Troque linear por ease-in-out — fica mais suave
