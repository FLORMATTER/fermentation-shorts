Aula 4 — Troca de cenas com JavaScript

Aula 4 de 4. É a última e a mais importante: é este motor que faz todos os seus vídeos funcionarem.

Como usar: leia de cima para baixo. No meio da aula tem uma tela de verdade rodando — aperte play e veja as cenas trocando sozinhas. É exatamente o motor dos seus shorts.

1. O problema que o JavaScript resolve

Nas aulas 1 a 3 você aprendeu a desenhar (HTML), pintar (CSS) e animar cada peça (keyframes).

Mas tem uma coisa que o CSS sozinho não faz: trocar uma cena inteira por outra, na hora certa, e parar no fim.

Pensa num short seu: são 8 telas diferentes passando uma atrás da outra. Alguém precisa ficar contando "1... 2... 3... agora!". Esse alguém é o JavaScript.

Quem fazO quê
HTMLDesenha as 8 telas (as <svg>)
CSSPinta e anima cada peça dentro da tela
JavaScriptDecide qual das 8 está aparecendo e quando trocar

2. A ideia toda em uma frase

Todas as 8 telas existem ao mesmo tempo no arquivo. Só uma está visível. O JavaScript liga uma e desliga as outras.

É isso. Não tem mágica. As 8 telas ficam empilhadas no mesmo lugar, uma em cima da outra. Por padrão todas estão invisíveis (opacity: 0). O JavaScript só dá permissão para uma aparecer.

3. As duas classes de CSS

Precisa de duas regras: uma para as telas escondidas, outra para a tela ligada.

<style>
  svg.cena {
    position: absolute; inset: 0;   /* todas no mesmo lugar */
    opacity: 0; visibility: hidden; /* escondida        */
    transition: opacity .42s ease;  /* troca suave      */
  }
  svg.cena.ligada {
    opacity: 1; visibility: visible; /* apareceu */
  }
</style>

position: absolute; inset: 0 é o que faz todas ficarem empilhadas no mesmo lugar. Sem isso elas ficariam uma embaixo da outra, e você veria as 8 de uma vez.

A segunda regra só vale para quem tiver a classe ligada. Como o nome já diz: quem está ligado, aparece.

Por isso o nome "classe ligada": dar ou tirar a classe ligada é o único gesto que o JavaScript faz. Toda a troca de cena é isso.

4. O quadro de cenas (scenes)

Agora o coração. No fim do arquivo, dentro de <script>, você escreve uma lista com todas as cenas. Cada linha diz: qual tela, quanto tempo, e o que escrever embaixo.

const scenes = [
  { id:'s0', ms:6000, cap:'Só as mãos. Sem rosto.', sub:'1 repolho, 7 dias', color:'#2c2c2a' },
  { id:'s1', ms:6000, cap:'Lava e tira as folhas',  sub:'água fria',       color:'#2b6a80' },
  { id:'s2', ms:6500, cap:'Corta bem fino, 2 mm',   sub:'grosso fica duro', color:'#3b6d11' }
];
PeçaO que é
idO nome da tela. Tem que ser igual ao id="s0" do SVG.
msQuantos milissegundos essa cena fica na tela. 6000 = 6 segundos.
capA legenda (letra grande, embaixo).
subA sublegenda (letra pequena, abaixo da legenda).
colorA cor da barra de progresso no topo.
Erro nº1 de quem começa: escrever id:'s0' na lista e id="tela0" no SVG. Se os dois nomes não forem idênticos, a cena nunca aparece — e a tela fica preta. Confira sempre letra por letra.

5. A peça que conta o tempo — setInterval

Como o JavaScript sabe que passaram 6 segundos? Com um despertador que toca a cada pedacinho de tempo.

const RES = 70;   // toca a cada 70 milissegundos (~14x por segundo)

tick0 = setInterval(() => {
  elapsed += RES;                 // soma 70 ao tempo que passou
  if (elapsed >= scenes[i].ms) {   // já passou do tempo da cena?
    i++;                          // vai para a próxima
    elapsed = 0;                  // zera o cronômetro
    render();                     // redesenha
  }
}, RES);

É só isso: a cada 70ms ele soma 70 ao tempo decorrido. Quando o tempo acumulado chega no ms da cena, pula para a próxima.

Por que 70 e não 1000 (1 segundo)? Porque a barra de progresso precisa ficar lisa. Se o relógio tocasse de segundo em segundo, a barra andaria aos pulos.

6. A função que troca a cena — render()

Esta é a única função que faz a troca de verdade. São 4 linhas:

function render() {
  // 1. desliga TODAS as telas
  scenes.forEach((s, n) => {
    const el = document.getElementById(s.id);
    el.classList.remove('ligada');
    // 2. liga só a que está na vez
    if (n === i) el.classList.add('ligada');
  });

  // 3. escreve a legenda
  capEl.innerHTML = scenes[i].cap + '<small>' + scenes[i].sub + '</small>';

  // 4. pinta a barra com a cor da cena
  progress.style.background = scenes[i].color;
  progress.style.width = '0%';
}

Traduzindo para o português:

  1. Tira a classe ligada de todas as telas (todas somem).
  2. Põe a classe ligada na tela da vez (só ela aparece).
  3. Escreve o texto da legenda.
  4. Deixa a barra do topo na cor certa e zera ela.
Guarde esta função. Ela é idêntica em todos os seus 7 shorts e no player do vídeo longo. Muda só a lista scenes e os desenhos.

7. As 4 variáveis de controle

let i = 0;              // qual cena está na vez (começa na 0)
let playing = false;    // está tocando?
let tick0 = null;       // o despertador (guardado para poder parar)
let elapsed = 0;        // quanto tempo já passou da cena atual

Presta atenção no i: ele é só um número. Não é a cena, é a posição da cena na lista. Se i vale 2, estamos mostrando scenes[2] — a terceira cena, porque a lista começa a contar do zero.

Contar do zero: em programação a primeira posição é a 0, não a 1. scenes[0] é a primeira cena, scenes[7] é a oitava. Isso confunde no começo, mas é regra fixa.

8. Play e Pause

function play() {
  playing = true;
  elapsed = 0;
  btnPlay.textContent = '⏸ Pausar';
  render();   // desenha a cena atual
  loop();     // liga o despertador
}

function stop() {
  playing = false;
  btnPlay.textContent = '▶ Assistir';
  clearInterval(tick0);   // desliga o despertador
}

Repare: o pause não esconde nada. Ele só desliga o despertador (clearInterval). A cena continua na tela, congelada, esperando você apertar play de novo. É por isso que pausar e continuar funciona tão bem.

10. Como montar um short do zero

São 4 passos, sempre na mesma ordem:

Passo 1 — Desenhe cada cena como um <svg>

Um por cena, cada um com seu id. O primeiro leva a classe ligada:

<svg class="cena ligada" id="s0" viewBox="0 0 405 720"> ... </svg>
<svg class="cena" id="s1" viewBox="0 0 405 720"> ... </svg>
<svg class="cena" id="s2" viewBox="0 0 405 720"> ... </svg>

Passo 2 — Escreva a lista scenes

Uma linha por cena, na mesma ordem dos SVGs, com os ids iguais:

const scenes = [
  { id:'s0', ms:6000, cap:'Título da cena', sub:'sub', color:'#3b6d11' },
  { id:'s1', ms:6000, cap:'Segunda cena',   sub:'sub', color:'#d85a30' },
  { id:'s2', ms:6500, cap:'Terceira cena',  sub:'sub', color:'#3b6d11' }
];

Passo 3 — Copie o motor

As funções render(), loop(), play(), stop() e toggle(). Já estão prontas — é só copiar de um short que funciona e colar.

Passo 4 — Ligue o motor no fim

render();   // desenha a primeira cena ao abrir
