Aula 2 — Cores e tamanhos

Aula 2 de 4 — versão resumida. Só o que você precisa pra mexer nos vídeos.

Como usar: leia de cima para baixo, são só 5 blocos. Onde aparecer um quadrado colorido, é o resultado do código acima dele.

1. Onde o CSS fica

O CSS mora dentro de <style>, no topo do arquivo. Ele diz como cada coisa se parece.

<style>
  body { background: #fdf9f3; }
  h1   { color: #3b6d11; font-size: 30px; }
</style>

A regra tem sempre 3 pedaços:

h1   {   color: #3b6d11 ;  }
↑        ↑     ↑      ↑
quem    abre  o que   fecha

2. Cores — os 3 jeitos

JeitoExemploQuando usar
Hexadecimal#3b6d11É o que uso nas animações. Preciso e curto.
Nomered, whiteSó para testes rápidos. Tem poucas opções.
RGBrgb(59,109,17)Quando quer regular a transparência: rgba(59,109,17,.5)

Como ler um hexadecimal: são 6 letras/números em 3 pares — vermelho, verde, azul. #3b6d11 é 3b de vermelho, 6d de verde, 11 de azul. Verde baixinho, então a cor é verde-escuro.

#3b6d11
#7d8c46
#ba7517
#d85a30
#2c2c2a

Essas 5 são as cores que mais uso. O #2c2c2a é quase-preto — nunca use #000000 puro, ele deixa o desenho duro.

Dica do pega-fácil: experimente qualquer cor em coolors.co. Ele mostra o código hexadecimal pronto pra copiar.

3. Onde pintar

CódigoO que pinta
colorA letra (o texto)
backgroundO fundo do quadrado
borderA borda em volta
fillDentro de SVG: o miolo da forma
strokeDentro de SVG: o contorno da forma
.caixa {
  color: #2c2c2a;          /* texto quase-preto */
  background: #faeeda;     /* fundo bege        */
  border: 3px solid #ba7517; /* borda laranja   */
}
Resultado: fundo bege, borda laranja, texto quase-preto.
Atenção: dentro de SVG as cores usam fill e stroke, não color/background. Se você pintar um <rect> com background, não vai funcionar.

4. Tamanhos de texto

Usa font-size. A unidade é o px (pixel).

h1 { font-size: 48px; }
p  { font-size: 16px; }

12px — legenda bem pequena

16px — texto normal, o padrão

22px — subtítulo

30px — título

48px — número gigante

Por que importa: no celular, o vídeo tem 405px de largura. Se o texto da legenda passar de 18px, ele quebra e fica feio. Minha regra: legenda de 16px, título de 22 a 30px, o número principal de 48px.

5. Largura, altura e espaçamento

CódigoPara que serve
width: 405pxLargura
height: 720pxAltura
padding: 20pxEspaço por dentro (afasta o texto da borda)
margin: 20pxEspaço por fora (afasta dos vizinhos)
border-radius: 12pxCantos arredondados
gap: 10pxEspaço entre itens lado a lado
#stage {
  width: 405px;      /* a tela do short      */
  height: 720px;     /* 9:16 na vertical     */
  background: #f4efe4;
  border-radius: 16px;
}
O tamanho do vídeo: 405 × 720 é a proporção 9:16 (o formato do Shorts). Mantenha sempre essa proporção — se mudar só um dos números, o desenho entorta.
