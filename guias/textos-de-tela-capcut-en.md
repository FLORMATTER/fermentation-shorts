# On-Screen Text — for CapCut Overlays (ENGLISH)

These are the texts you add **on top of** the recorded video as a layer in CapCut.
They create the "hook" and explain in big text — the format that works best on Shorts.

**Audience: international.** Everything here is in English on purpose.

> PT-BR version of this file: `textos-de-tela-capcut.md`

---

## 📐 HOW TO USE IN CAPCUT (PC)

1. **Text** (top menu) → **Add default text**
2. Paste the text from the list below
3. In the **Text** tab (right panel): pick a **very bold** font (like Poppins Bold, Montserrat ExtraBold)
4. Under **Background**, add a dark box — guarantees readability on any background
5. **Position:** **upper third** or **center** — never at the bottom (the YouTube caption and the buttons cover it)
6. **Duration:** drag the text handle on the timeline to where it should appear
7. Under **Animation**, pick **Typewriter** or **Appear** — text that enters with movement retains more viewers

### Shortcuts that help on PC

| Shortcut | What it does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | Splits the clip in two (to remove a piece) |
| <kbd>Delete</kbd> | Deletes the selected piece |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd> + <kbd>scroll</kbd> | Zoom the timeline |

### Rules that apply to all

| Rule | Why |
|---|---|
| **Max 6 words per screen** | The brain doesn't read more than that while scrolling |
| **Dark background + white text** (or a box behind it) | Guarantees readability on any background |
| **First 2 seconds = the hook** | That's what stops the scroll |
| **Never cover the main drawing** | Text supports, it doesn't hide |
| **ALL CAPS only in the hook** | If everything is caps, nothing stands out |

# ⚡ SHORT VERSION (30s) — if you want to speed it up

If the video is too fast to read everything, use only **3 texts**:

```
1. [HOOK]    0s – 2s      the top title
2. [NUMBER]  8s – 12s     the main data point (salt / time)
3. [WARNING] last 3s      the mistake to avoid
```

Those 3 are the ones that really make a difference. The rest is a bonus.

---

# 📌 THE HOOK IS EVERYTHING

If you can only get **one** thing right, get the 2-second hook right.

**Formulas that work:**

| Formula | Example |
|---|---|
| **The mistake** | `YOU'RE DOING THIS WRONG` |
| **The warning** | `YOUR HANDS WILL TURN PINK` |
| **The absurd number** | `2 INGREDIENTS. THAT'S IT.` |
| **The confession** | `I GOT THIS RECIPE WRONG 3 TIMES` |
| **The contradiction** | `IT'S NOT 2%. IT'S 2.5%.` |
| **The question** | `WHY DO PICKLES GO SOGGY?` |

Pick **one** formula per video. Don't mix them.
