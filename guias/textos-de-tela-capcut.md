# Textos de Tela — pra sobrepor no CapCut

Estes são os textos que você adiciona **por cima** do vídeo gravado, como camada no CapCut.
Servem pra dar o "gancho" e explicar em texto grande (formato que funciona muito bem em Shorts).

---

## 📐 COMO USAR NO CAPCUT (PC)

1. **Texto** (menu de cima) → **Adicionar texto padrão**
2. Cole o texto da lista abaixo
3. Na aba **Texto** (painel da direita): escolha uma fonte **bem grossa** (tipo Poppins Bold, Montserrat ExtraBold)
4. Em **Fundo**, coloque uma caixinha escura — garante leitura em qualquer fundo
5. **Posição:** no **terço superior** ou no **centro** — nunca embaixo (a legenda do YouTube e os botões cobrem)
6. **Duração:** arraste a alça do texto na linha do tempo até onde ele deve aparecer
7. Em **Animação**, escolha **Digitar** ou **Aparecer** — texto que entra com movimento retém mais

### Atalhos que ajudam no PC

| Atalho | O que faz |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | Corta o clipe em dois (pra remover pedaço) |
| <kbd>Delete</kbd> | Apaga o pedaço selecionado |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Desfaz |
| <kbd>Ctrl</kbd> + <kbd>scroll</kbd> | Zoom na linha do tempo |

### Regras que valem pra todos

| Regra | Por quê |
|---|---|
| **Máximo 6 palavras por tela** | Cérebro não lê mais que isso enquanto rola |
| **Fundo escuro + texto branco** (ou uma caixinha atrás) | Garante leitura em qualquer fundo |
| **Primeiros 2 segundos = o gancho** | É o que faz parar de rolar |
| **Nunca cubra o desenho principal** | O texto apoia, não tapa |
| **Letras MAIÚSCULAS só no gancho** | Se tudo for maiúsculo, nada se destaca |

# ⚡ VERSÃO CURTA (30s) — se quiser acelerar

Se o vídeo for muito rápido pra ler tudo, use só **3 textos**:

```
1. [GANCHO]    0s – 2s      o título de cima
2. [NÚMERO]    8s – 12s     o dado principal (sal / tempo)
3. [AVISO]     último 3s    o erro a evitar
```

Esses 3 são os que realmente fazem diferença. O resto é bônus.

---

# 📌 O GANCHO É TUDO

Se você só puder acertar **uma** coisa, acerte o gancho dos 2 primeiros segundos.

**Fórmulas que funcionam:**

| Fórmula | Exemplo |
|---|---|
| **O erro** | `VOCÊ ESTÁ FAZENDO ISSO ERRADO` |
| **O aviso** | `SUA MÃO VAI FICAR ROSA` |
| **O número absurdo** | `2 INGREDIENTES. SÓ ISSO.` |
| **A confissão** | `EU ERREI ESSA RECEITA 3 VEZES` |
| **A contradição** | `NÃO É 2%. É 2,5%.` |
| **A pergunta** | `POR QUE O PEPINO FICA MOLE?` |

Escolha **uma** fórmula por vídeo. Não misture.
